# 🎓 Student Grade Calculator using Python

## 📌 Project Description

The Student Grade Calculator is a Python-based project that calculates a student's total marks, percentage, grade, and final result based on marks entered for different subjects.

## 🛠️ Technologies Used

* Python
* Conditional Statements
* User Input
* Arithmetic Operations

## 📚 Subjects

The project currently accepts marks for:

* Python
* Operating Systems
* Mathematics
* DBMS

## ⚙️ Features

* Enter student name
* Enter marks for each subject
* Calculate total marks
* Calculate percentage
* Calculate grade
* Display PASS or FAIL result

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the Python file:

```bash
python student_grade.py
```
